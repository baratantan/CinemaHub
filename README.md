# CinemaHub

تطبيق Android لعرض كتالوج الأفلام ومتابعة المفضلة وسجل المشاهدة، بواجهة عربية مبنية باستخدام Kotlin وJetpack Compose.

## مراجعات وتقييمات الأفلام (Firebase)
تظهر المراجعات مباشرة أسفل تفاصيل الفيلم. يختار المستخدم تقييماً من 1 إلى 5 نجوم، ويكتب اسماً وتعليقاً؛ تحفظ المراجعة في Cloud Firestore وتُحدّث القائمة ومتوسط التقييم لحظياً. يحتفظ كل حساب بمراجعة واحدة لكل فيلم، ويمكنه تعديلها بإرسال تقييم جديد. يُنشئ التطبيق حساب Firebase مجهولاً تلقائياً، وتبقى هذه الهوية على الجهاز؛ ربط الحساب لتزامن الهوية بين الأجهزة يحتاج إضافة تسجيل دخول دائم.

### تهيئة Firebase
1. أنشئ مشروع Firebase، وأضف تطبيق Android بمعرّف `com.cinemahub.app`.
2. فعّل **Authentication → Sign-in method → Anonymous** وفعّل **Cloud Firestore**.
3. انشر قواعد `firestore.rules` إلى قاعدة Firestore. القواعد تتطلب المصادقة، وتسمح للمستخدم بتعديل/حذف مراجعته فقط.
4. زوّد Gradle بقيم تطبيق Firebase (هذه بيانات عميل عامة وليست أسرار خادم):

```properties
FIREBASE_API_KEY=...
FIREBASE_APP_ID=...
FIREBASE_PROJECT_ID=...
```

ضعها في `~/.gradle/gradle.properties` محلياً أو في Gradle secrets لمهمة CI. لا تضع مفاتيح Service Account أو بيانات اعتماد إدارية في التطبيق أو المستودع. عند غياب الإعدادات، تبقى بقية الشاشات متاحة وتعرض ميزة المراجعات رسالة إعداد Firebase.

## المتطلبات
- Android Studio مع Android SDK 34
- JDK 17 (يوصى به مع Android Gradle Plugin 8)
- اتصال بالإنترنت لتنزيل Gradle والاعتماديات

## التشغيل
1. افتح المشروع في Android Studio وانتظر اكتمال Gradle Sync.
2. شغّل مهمة `:app:assembleDebug` أو اختر Run على محاكي/جهاز.
3. اختبر التطبيق يدويًا على جهاز فعلي، بما في ذلك الشبكة، تدوير الشاشة، وتوافق مشغل الفيديو.

## بناء نسخة الإصدار
أنشئ مفتاح توقيع خارج المستودع، واحفظ أسراره في `~/.gradle/gradle.properties` أو متغيرات CI؛ لا تضع كلمات المرور أو ملف keystore في المستودع.

بناء AAB من Android Studio: **Build → Generate Signed Bundle / APK → Android App Bundle**. لا تنشر النسخة قبل اختبار ملف AAB الموقّع على مسار داخلي.

## حدود معروفة
- لا توجد حاليًا خدمة كتالوج/بيانات حقيقية أو API إعداد؛ يلزم توفير بيانات قانونية قبل الإطلاق العام.
- شاشة المشاهدة لا تُظهر عناصر حتى تُسجل عملية مشاهدة؛ سجل التقدم يحتاج ربطًا كاملًا بأحداث المشغل.
- تشغيل روابط iframe أو روابط صفحات ويب ليس مضمونًا؛ مشغل Media3 يحتاج روابط بث مباشرة بصيغ مدعومة.
- حسابات المراجعات مجهولة ومقيدة بالجهاز حالياً؛ تسجيل الدخول الدائم ومزامنة الهوية عبر الأجهزة غير مفعّلين.

## الخصوصية والامتثال
أضف سياسة خصوصية، معلومات دعم، وأي إفصاحات مطلوبة من Google Play بناءً على بيانات التطبيق الفعلية. لا تستخدم scraping لمحتوى لا تملك حق الوصول إليه.
