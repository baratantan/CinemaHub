# CinemaHub

تطبيق Android لعرض كتالوج الأفلام ومتابعة المفضلة وسجل المشاهدة، بواجهة عربية مبنية باستخدام Kotlin وJetpack Compose.

> تنبيه: يجب أن يكون المحتوى وروابط الفيديو التي يضيفها المستخدم مرخّصة أو مملوكة له. لا يتضمن هذا المشروع خدمة توزيع محتوى مرئي أو API رسميًا؛ تحقق من حقوق النشر وسياسات المتجر قبل النشر.

## المتطلبات
- Android Studio مع Android SDK 34
- JDK 17 (يوصى به مع Android Gradle Plugin 8)
- اتصال بالإنترنت لتنزيل Gradle والاعتماديات

## التشغيل
1. افتح المشروع في Android Studio وانتظر اكتمال Gradle Sync.
2. شغّل مهمة `:app:assembleDebug` أو اختر Run على محاكي/جهاز.
3. اختبر التطبيق يدويًا على جهاز فعلي، بما في ذلك الشبكة، تدوير الشاشة، وتوافق مشغل الفيديو.

## بناء نسخة الإصدار
أنشئ مفتاح توقيع خارج المستودع، واحفظ أسراره في `~/.gradle/gradle.properties` أو متغيرات CI؛ لا تضع كلمات المرور أو ملف keystore في Git. تحقق من `applicationId` و`versionCode` و`versionName` وسياسة target SDK المطلوبة للنشر قبل إصدار AAB.

بناء AAB من Android Studio: **Build → Generate Signed Bundle / APK → Android App Bundle**. لا تنشر النسخة قبل اختبار ملف AAB الموقّع على مسار داخلي في Google Play Console.

## حدود معروفة
- لا توجد حاليًا خدمة كتالوج/بيانات حقيقية أو API إعداد؛ يلزم توفير بيانات قانونية قبل الإطلاق العام.
- شاشة المشاهدة لا تُظهر عناصر حتى تُسجل عملية مشاهدة؛ سجل التقدم يحتاج ربطًا كاملًا بأحداث المشغل.
- تشغيل روابط iframe أو روابط صفحات ويب ليس مضمونًا؛ مشغل Media3 يحتاج روابط بث مباشرة بصيغ مدعومة.

## الخصوصية والامتثال
أضف سياسة خصوصية، معلومات دعم، وأي إفصاحات مطلوبة من Google Play بناءً على بيانات التطبيق الفعلية. لا تستخدم scraping إلا وفق شروط المواقع والحقوق القانونية.
